# TGUI Vendor Package with SFML-GRAPHICS Backend
This vendor package provides the TGUI library which can use different rendering back-ends.
This package specifically uses the SFML_GRAPHICS back-end which is highly cross-platform.
See [the TGUI docs](https://tgui.eu/tutorials/latest-stable/backends/) for details and [TGUI tutorials](https://tgui.eu/tutorials/latest-stable/backend-sfml-graphics/) for examples.
